\section{Virtualisation Efficiency Benefits}
\subsection{Understanding virtualization}
Virtualization in simple terms is the sharing of physical resources between mul- tiple virtual machines. You can think of it as a "computer within a computer, implemented in software."\cite{2.zdroj} This is done by creating an abstraction layer over the physical hardware of the host machine so multiple computers (Virtual Ma- chines) can run on one hardware. They can also share resources such as network cards, CPU, memory, Physical storage and others. The virtual machine is a vir- tual depiction of machine hardware which is maintained by a virtual machine monitor (VMware Fusion, Oracle VM VirtualBox). Concept shown in Figure ~\ref{fig:AD}. The concept of virtualization, isn’t new it has been here since 1960. But with the introduction of X86 Architecture and platforms, it has been been sought out by many companies because it provided simple seamless implementation without significant interruption to operations and low acquisition.

\subsection{Benefits of Virtualization}
The benefits of virtualization are considerable. Virtualization can help with security, scalability, cost-cutting, efficient uses of resources and others. Non-virtualized systems can be inefficient when non-virtualized resources aren’t in use and the hardware is sitting idle without any computing tasks ready to run. While in a virtualized system once resources become available hypervisor can allocate them accordingly to another task so the physical resources are always in use. With this comes another benefit of security and corruption prevention where in normal non-virtualized systems the security and backup lay on one specific machine and user. The virtualized system security depends on the security of the whole system. This can lead to damage prevention where we can back up each VM, so in case of a natural disaster, there isn’t any loss of data. In simple terms, virtualization helps with the growth and scalability of an organization.


For ACME Games virtualization will not only help with cost-cutting and security but also with
\begin{enumerate}
	\item Minimize Servers 
	\item Reduce Hardware
	\item Quick Redeployment
	\item Simpler Backups 
	\item Better Testing
\end{enumerate}

\subsection{Cost of virtualization and energy efficiency}
This section delves into the total cost of ownership for virtualized systems compared to standard systems and the energy efficiency of medium to large organizations. We will look into to direct and indirect costs of virtualization for organizations. Real-life examples of companies that went through a restructuring of their servers to implement virtualization.

\subsubsection{Cost of virtualization}
First, we need to define what the major direct cost categories for an organization to implement a virtualized system are:
\begin{enumerate}
	\item Hardware cost

	These are represented as expenses incurred so virtualization can be implemented in the system. Primarily physical technologies that would allow to create new virtualized system \cite{2.zdroj}
	\item Software cost

	These are expenses derived from buying and/or licensing software which allows access to virtual machines and all its possible functions \cite{2.zdroj}
	\item Deployment costs
 
	These costs are expenses associated with things like disruption to existing operations and space improvement, which would be necessary for the implementation of the virtualized system.
\end{enumerate}
These are direct costs of implementing virtualization they can be one-time or recurring. These expenses (explained later in depth) represent the general figure for medium to large firms. These can be cut down further with the right licensing agreement and the right negotiation with hardware providers.

There are also indirect costs when implementing virtualization, such as:
\begin{enumerate}
	\item Training personnel cost
	\item Maintenance cost
	\item Energy cost
\end{enumerate}

\section{Security Issues}
Any technological enterprise’s biggest concern is the mitigation of unauthorized access to company data. This unauthorized access can be within the company’s corporate hierarchies or a malicious attack by a third party. While access per- mission within a company’s structure is achieved by setting up correct entry dispensation and secured data movement infrastructure within the company’s internal systems, third-party attacks are harder to prognosticate, therefore es- establishing robust threat assessment and a durable security panel is exceedingly important compared to other parts of virtualization.

\subsection{Operating system security issues}
In today’s technological world operating systems are found everywhere. This results in daily exponential improvements in developing malicious techniques to infect our Operating systems.
Here are some common vulnerabilities that can be exploited:

\begin{enumerate}
	\item Buffer Overflow
	\item Code Injections
	\item Privilege Escalation
	\item Denial of Service
	\item Zero-Day
\end{enumerate}
A great example is Microsoft’s vulnerability issue from 2023 which was patched in February 2024 and tracked under code CVE-2024-21338. This issue affected the kernel mode in different versions of Windows 10 and 11. This exploit used the CWE-822 weakness where the attacker supplies an internal pointer for memory location which wasn’t expected. If the pointer dereferences into write, the attacker can start modifying the variables or carry out code execution. On the other hand, dereferencing pointer to read allows the reading of sensitive data. This issue falls into the Zero-Day exploit. This CWE-822 issue can be exploited in any language that uses pointers (c/c++, assembly...)\cite{8.zdroj}\cite{9.zdroj}

\vspace{1.5cm}
his part explores the most common operating system security issues.

\paragraph{Buffer overflow}occurs when more information is written to the buffer beyond its memory. Buffer overflow attacks on a system aim to modify the state of memory so that a third party can execute code that allows it to take over the machine. This is done by precisely inputting data so that the buffer would copy this information to the adjacent location in memory.


\paragraph{Code Injections} is a security exploitation where a program misinterprets input data as part of its code. Figuratively the attacker injects code into the run of the program and changes its behavior to gain access to the machine.

\paragraph{Privilege Escalation}  is accomplished by exploiting systems or a program’s vulnerability to gradually gain access to different resources and modes of the operating system. This way attackers can go from user mode with the least amount of privilege to the kernel mode to change the behavior of the OS.

\paragraph{Denial of Service} attacks are meant to disrupt the network for the intended user so they cannot use it. In these attacks a third party floods the network with a large amount of requests which it can’t handle, eventually shutting the network down.


\paragraph{Zero-Day} exploitation of a software issue that developers don’t know about. This isn’t any specific common issue being exploited. In this scenario, attackers are trying to find software vulnerabilities faster than developers can find them.

\subsubsection{Most common security risks in virtualized environment }
\paragraph{VM Sprawl}
Virtual machine sprawl occurs when an unmanaged number of VMs are created for one specific task and forgotten about. This leads to a waste of resources as already existing VMs take up resources that aren’t in use and could be utilized elsewhere. Also, if VMs are left unchecked for prolonged periods of time, vulnerabilities can be created by out-of-date VMs which can be used to access the inner system, resulting in the potential loss of sensitive data. This can be mitigated by creating VM lifecycle insurance or by strict laws under which VMs can be created, managed and terminated.

\paragraph{Malware attacks}
VMs like any other computing technology are susceptible to malware attacks. This can be a bigger danger in a virtualized environment when users of VMs don’t have proper security training which can lead to the infection of a VM. This wouldn’t be a significant in a normal system but in virtualization, this can lead to the spread of malicious software to the host machine and all other VMs that run on that same physical machine. This can be mitigated by setting up Firewalls, Host intrusion prevention systems and anti-virus/spyware.
\paragraph{Oragnization issues}
Virtualization is dominating the technical aspects of companies around the world. That is why all the issues above are being closely monitored by software providers, cyber security companies and other parties. When implementing a virtualized system, the IT corporate structure is often neglected, the additional workload created by the implementation cannot be left to the existing IT team as this could lead to catastrophic scenarios. That’s why the IT department needs to maintain great standards and integrity in areas like Monitoring VMs, setting up access control, separation of duties, hardening and making sure that the change of management is seamless.\cite{14.zdroj}

\section{File System Scripting}
This section explains the thinking and reason behind the first bash script. With this script, we aimed and successfully created two groups of users each group had a userxy who acted as a supervisor. These groups had their own folders where only the group members could access them and userxy. Each user had their own folder created in their group folder and only that specific user and userxy could read write and execute anything in this personal folder.

This is the 1st part of the script. Here we run everything with sudo to make sure we don't get any permission denied errors.

sudo groupadd <name> creates 2 groups. With that done, we create two directories for each group with the command sudo mkdir <name>.  By stating /home/group01Project we ensured that the directories were created in the home folder of Ubuntu. Next, we create userxy and add him to each group. After that, we set permissions for each group and for the userxy. For this, we used the Acces Control List first we set read, write, execute (later rwx) permission for each group for their home folder. These permissions were general so they can't access any new folders created in their home directory. Then we set rwx permissions which are initiated for new folders created in the group home folder. These permissions were given to userxy.

In the second part of the script, we created two arrays which hold the names of each user who is in the specific group. We run through the array with a for loop.
\begin{enumerate}
	\item sudo adduser \textdollar users01

		Creates the specific user whose name is in the array. We used adduser to create an account with a more interactive experience and full features rather then useradd where we would need to specify everything.

	\item sudo usermod -a -G group01 \textdollar users01
	With this line, we add the user to the specific group

	\item sudo mkdir /home/group01Project/ \textdollar users01

		this line creates name specific folder in the group01Project

	\item sudo setfacl -m d:u:\textdollar users01:rwx /home/group01Project/\textdollar users01

		Here we set specific inherited rwx permissions for the users personal folder  

	\item echo "created user \textdollar users01"

		Prints the name of the user which was created
\end{enumerate}
