\subsection{Benefity of Virtualization}
The benefits of virtualization are considerable. Virtualization can help with  security,scabalety, cost cutting, efficent uses of resorces  and other.
Non virtualized system can be inefficent when non virtulzed resorces arent in use the hardware is sitting idle without any computing task ready to run. While virtulized system once resorces become avaible hypervisor can allocated them accrdingly to another task so the physical resorces are always in use. With this comes another benefit of  security and corruption prevention where in normal non virtulized system the security and backup layes on the one spesific machine and user. The Virulized system security deppends on security of the whole system. This can lead to better and secure dissaster prevention where we can back up each VM so in case of natural disaster there isn't any lost of data. In simple terms virtualization helps with growth scalebility of a organization.

 For ACME Games virtualization will not only help with cost cutting and security but also with:
\begin{enumerate}
	\item Minimize Servers 
	\item Reduce Hardware
	\item Quick Redeployment
	\item Simpler Backups 
	\item Better Testing
\end{enumerate}
